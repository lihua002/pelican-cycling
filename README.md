# 鹈鹕骑自行车 · Pelican Goes Cycling

一个纯网页的循环动画：一只大白鹈鹕骑着浅绿色复古自行车，穿行在春日公园的小路上，车篮里还装着一条小鱼。

## 动画效果

- 车轮持续转动，辐条旋转
- 鹈鹕的双脚与踏板、曲柄联动（真实圆周踩踏）
- 身体随骑行轻微颠簸，翅膀微微起伏
- 多层视差背景滚动：云朵、远山、近丘、树木、草丛、路面
- 太阳光芒缓慢旋转
- 右上角按钮可暂停 / 继续
- 支持桌面与手机竖屏自适应

## 如何查看

**方式一：在线查看（GitHub Pages）**

1. 打开仓库的 `Settings` → `Pages`
2. `Source` 选择 `Deploy from a branch`，分支选择 `main`、目录选择 `/ (root)`，保存
3. 稍等片刻，即可通过 `https://lihua002.github.io/pelican-cycling/` 访问

**方式二：本地查看**

下载 `index.html`，用浏览器直接打开即可，无需任何依赖。

## 技术栈

单个自包含的 `index.html`：原生 HTML + 内联 SVG + CSS Keyframes + 少量原生 JavaScript，无外部库、无构建步骤。
